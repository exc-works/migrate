# दस्तावेज़ मार्गदर्शिका

migrate बदलावों को क्रमबद्ध संस्करण फ़ाइलों में रखता है। डिप्लॉयमेंट में CLI या Go ऐप में लाइब्रेरी इस्तेमाल करें।

- शुरुआत: [SQLite](./quick-start), [इंस्टॉलेशन](./installation), [कॉन्फ़िगरेशन](./configuration)।
- प्रबंधन: [SQL](./sql-migrations), [लागू करना](./applying), [वापसी](./rollback), [इतिहास](./history)।
- डेटा: [स्क्रिप्ट](./scripting), [मॉड्यूल](./modules), [API](./script-api), [ट्रांज़ैक्शन](./script-transactions), [उदाहरण](./examples)।
- एकीकरण: [Go](./go-library), [SSH](./ssh-tunnels)।
- संदर्भ: [CLI](./commands), [डेटाबेस](./databases), [समस्याएँ](./troubleshooting)।

अपनी स्थापना की सुविधाएँ `migrate version` और [रिलीज़ नोट्स](../releases) से जाँचें।
