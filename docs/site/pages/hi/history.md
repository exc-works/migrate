# इतिहास और बेसलाइन

संस्करण, नाम और हैश को असली स्कीमा से तुलना करें।

```sh
migrate status
migrate status --output json
```

| स्थिति | अर्थ | कार्रवाई |
| --- | --- | --- |
| `pending` | लागू नहीं | जाँचकर `up` |
| `applied` | सफल | फ़ाइल बनाए रखें |
| `baseline` | बिना चलाए दर्ज | अपनाया इतिहास रखें |
| `outOfOrder` | पुराना लंबित | क्रम नीति जाँचें |
| `hashMismatch` | सामग्री बदली | मूल लौटाएँ |
| `filenameMismatch` | नाम बदला | मूल नाम लौटाएँ |

असंगति चलना रोकती है। नए बदलाव नया संस्करण हैं। स्क्रिप्ट हैश में [मॉड्यूल](./modules#checksums) नहीं आते।

## मौजूदा डेटाबेस अपनाएँ {#baseline}

केवल जब स्कीमा और डेटा फ़ाइलों के अनुरूप हों:

1. असली स्थिति और फ़ाइलें मिलाएँ।
2. ज़रूरत हो तो `migrate create`।
3. `migrate baseline`, फिर `migrate status`।
4. अगले बदलाव उच्च संस्करण में।

बेसलाइन कोड नहीं चलाता और आंशिक विफलता नहीं सुधारता।
