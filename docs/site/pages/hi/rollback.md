# माइग्रेशन वापस लें

Down या `down(db)` वही उलटता है जो उसके कोड में है; हटे डेटा को अपने-आप नहीं लौटाता।

```sh
migrate down 202611030001 --dry-run
migrate down 202611030001
migrate status
```

लक्ष्य सुरक्षित, केवल उससे ऊपर के संस्करण वापस। 1, 2, 3 में `down 2` केवल 3 वापस लेता है।

```sh
migrate down --all --dry-run
migrate down --all
migrate status
```

लक्ष्य और `--all` एक साथ नहीं। सफलता पर `pending` लौटता है। पूरा दायरा और [ट्रांज़ैक्शन](./script-transactions) जाँचें। down गायब हो तो दायरा रुकता है; खाली down बदलाव नहीं उलटता। DDL और गैर-ट्रांज़ैक्शन बदलाव विफलता के बाद रह सकते हैं।
