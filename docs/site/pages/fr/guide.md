# Plan de la documentation

migrate conserve les changements dans des fichiers versionnés et ordonnés. Utilisez la CLI dans un déploiement ou intégrez le service dans une application Go.

- Pour commencer : [SQLite](./quick-start), [installation](./installation), [configuration](./configuration).
- Pour gérer les changements : [SQL](./sql-migrations), [exécution](./applying), [annulation](./rollback), [historique](./history).
- Pour transformer les données : [scripts](./scripting), [modules](./modules), [API](./script-api), [transactions](./script-transactions), [exemples](./examples).
- Pour intégrer : [Go](./go-library), [SSH et proxys](./ssh-tunnels).
- Pour consulter : [commandes](./commands), [bases compatibles](./databases), [dépannage](./troubleshooting).

Consultez `migrate version` et les [notes de version](../releases) pour les fonctionnalités de votre installation.
