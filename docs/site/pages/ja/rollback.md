# ロールバック

各ファイルの Down または `down(db)` を実行します。そのコードが実装した操作だけを取り消せます。削除したデータが自動的に復元されるわけではありません。

## 指定バージョンを保持

```sh
migrate down 202611030001 --dry-run
migrate down 202611030001
migrate status
```

指定したバージョンより上だけを戻します。1、2、3 が適用済みなら `down 2` は 3 だけを戻し、1 と 2 は残ります。

## すべて戻す

```sh
migrate down --all --dry-run
migrate down --all
migrate status
```

対象バージョンと `--all` は併用できません。成功したファイルは `pending` に戻り、再適用できます。

## 対象全体を確認

すべての Down と[トランザクション動作](./script-transactions)を確認します。対象スクリプトに `down(db)` がないと、範囲全体を実行できません。空の関数では変更は戻りません。DDL の暗黙のコミットや非トランザクション操作は失敗後も残る場合があります。
