# ドキュメント一覧

migrate は変更をバージョン付きファイルとして管理します。CLI をデプロイ手順に組み込むことも、Go アプリケーションから呼び出すこともできます。

## はじめに

[SQLite クイックスタート](./quick-start)で作成、実行、ロールバックを試せます。既存のプロジェクトには[インストール](./installation)と[設定](./configuration)を参照してください。

## 目的から探す

- [SQL の作成](./sql-migrations)、[実行](./applying)、[ロールバック](./rollback)、[履歴とベースライン](./history)。
- [スクリプト](./scripting)、[共有モジュール](./modules)、[データベース API](./script-api)、[トランザクションと制限](./script-transactions)、[実行可能なサンプル](./examples)。
- [Go との連携](./go-library)、[SSH とプロキシ](./ssh-tunnels)。
- [コマンド](./commands)、[対応データベース](./databases)、[問題の解決](./troubleshooting)。

リリースごとの機能は `migrate version` と[リリースノート](../releases)で確認できます。
