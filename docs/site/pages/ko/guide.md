# 문서 안내

migrate는 변경을 순서가 있는 버전 파일로 관리합니다. 배포에 CLI를 사용하거나 Go 애플리케이션에 통합할 수 있습니다.

- 시작: [SQLite](./quick-start), [설치](./installation), [설정](./configuration).
- 변경 관리: [SQL](./sql-migrations), [실행](./applying), [되돌리기](./rollback), [이력](./history).
- 데이터 처리: [스크립트](./scripting), [모듈](./modules), [API](./script-api), [트랜잭션](./script-transactions), [예제](./examples).
- 통합: [Go](./go-library), [SSH](./ssh-tunnels).
- 참조: [CLI](./commands), [데이터베이스](./databases), [문제 해결](./troubleshooting).

설치 버전은 `migrate version`과 [릴리스 노트](../releases)로 확인합니다.
