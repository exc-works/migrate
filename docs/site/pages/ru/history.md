# История и исходное состояние

История хранит версии, имена и хеши; сравнивайте с реальной схемой.

```sh
migrate status
migrate status --output json
```

| Статус | Значение | Действие |
| --- | --- | --- |
| `pending` | Не применено | Проверить и `up` |
| `applied` | Успех | Сохранить файл |
| `baseline` | Записано без выполнения | Сохранить принятую историю |
| `outOfOrder` | Старая ожидающая версия | Проверить порядок |
| `hashMismatch` | Содержимое изменено | Вернуть оригинал |
| `filenameMismatch` | Имя изменено | Вернуть имя |

Несовпадения блокируют. Новые изменения — новыми версиями. Хеш скрипта не включает [модули](./modules#checksums).

## Существующая база {#baseline}

Только если данные и схема уже соответствуют файлам:

1. Сравните реальное состояние с файлами.
2. При необходимости `migrate create`.
3. `migrate baseline`, затем `migrate status`.
4. Дальше добавляйте более высокие версии.

Baseline не выполняет код и не исправляет частичный сбой.
