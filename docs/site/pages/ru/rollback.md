# Откат миграций

Выполняет Down или `down(db)`: только написанную автором обратную операцию, без автоматического восстановления удалённых данных.

```sh
migrate down 202611030001 --dry-run
migrate down 202611030001
migrate status
```

Цель сохраняется, откатываются версии выше. Для 1, 2, 3 команда `down 2` отменяет только 3.

```sh
migrate down --all --dry-run
migrate down --all
migrate status
```

Цель и `--all` несовместимы. Успешный откат возвращает `pending`. Проверьте весь диапазон и [транзакции](./script-transactions). Отсутствие down блокирует диапазон; пустой down ничего не отменяет. DDL и нетранзакционные изменения могут сохраниться после ошибки.
