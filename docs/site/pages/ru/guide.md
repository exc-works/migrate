# Карта документации

migrate хранит изменения в упорядоченных файлах версий. Используйте CLI при развёртывании или библиотеку Go.

- Начало: [SQLite](./quick-start), [установка](./installation), [настройка](./configuration).
- Изменения: [SQL](./sql-migrations), [применение](./applying), [откат](./rollback), [история](./history).
- Скрипты: [написание](./scripting), [модули](./modules), [API](./script-api), [транзакции](./script-transactions), [примеры](./examples).
- Интеграции: [Go](./go-library), [SSH](./ssh-tunnels).
- Справка: [CLI](./commands), [базы](./databases), [неполадки](./troubleshooting).

Версию и доступные функции проверяйте через `migrate version` и [примечания](../releases).
