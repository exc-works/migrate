# التراجع عن الترحيلات

يشغّل Down أو `down(db)`، ويعكس فقط ما يطبقه هذا الكود دون استرجاع تلقائي للبيانات المحذوفة.

```sh
migrate down 202611030001 --dry-run
migrate down 202611030001
migrate status
```

يحتفظ بالإصدار الهدف ويلغي الأعلى فقط. عند وجود 1 و2 و3، يلغي `down 2` الإصدار 3 فقط.

```sh
migrate down --all --dry-run
migrate down --all
migrate status
```

الهدف و`--all` متنافيان. النجاح يعيد الحالة إلى `pending`. راجع النطاق كاملًا و[المعاملات](./script-transactions). غياب down يمنع النطاق، وdown فارغ لا يعكس شيئًا. قد تبقى تغييرات DDL والعمليات غير المعاملاتية بعد الفشل.
