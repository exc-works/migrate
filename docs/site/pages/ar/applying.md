# تطبيق الترحيلات

تحقق من الاتصال والملفات المستهدفة.

```sh
migrate create
```

ينشئ جدول السجل فقط عند الحاجة، ولا ينفذ الملفات. إن كانت التغييرات موجودة، راجع [نقطة البداية](./history#baseline).

```sh
migrate up --dry-run
migrate up
migrate status
```

تُطبق الإصدارات المعلقة بالترتيب ويُسجل النجاح. لا يعيد التشغيل الإصدارات المطبقة. قد لا يظهر خرج؛ افحص status. قد يتصل dry-run ويبدأ SSH لقراءة السجل، لكنه لا يطبق تغييرات ولا يقيّم السكربتات أو يتنبأ بـSQL الديناميكي.

تُتخطى الإصدارات المعلقة الأقدم افتراضيًا. فعّل `migrate_out_of_order` بعد التحقق من توافقها مع المخطط الحالي.

```sh
migrate --non-interactive up
migrate --non-interactive status --output json
```

قدّم المتغيرات والأسرار مقدمًا ونفذ أوامر القاعدة الواحدة بالتسلسل. لا يضمن السجل تنفيذًا وحيدًا مع التزامن أو الانهيار أو الالتزام الضمني. افحص الحالة قبل التكرار. انظر [المشكلات](./troubleshooting).
