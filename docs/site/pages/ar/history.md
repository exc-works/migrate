# السجل ونقطة البداية

يقيد السجل الإصدار والاسم والبصمة؛ قارنه بالمخطط الفعلي.

```sh
migrate status
migrate status --output json
```

| الحالة | المعنى | الإجراء |
| --- | --- | --- |
| `pending` | لم يطبق | راجع ثم `up` |
| `applied` | نجح | لا تعدّل الملف |
| `baseline` | سُجل دون تنفيذ | احتفظ بالسجل المعتمد |
| `outOfOrder` | معلق أقدم | راجع سياسة الترتيب |
| `hashMismatch` | تغيّر المحتوى | استعد الأصل |
| `filenameMismatch` | تغيّر الاسم | استعد الاسم |

الاختلاف يمنع التنفيذ. أضف إصدارًا للتغييرات الجديدة. بصمة السكربت لا تشمل [الوحدات](./modules#checksums).

## اعتماد قاعدة موجودة {#baseline}

فقط إذا كانت البيانات والمخطط مطابقين للملفات:

1. قارن الحالة الحقيقية والملفات.
2. استخدم `migrate create` عند الحاجة.
3. نفذ `migrate baseline` ثم `migrate status`.
4. أضف إصدارات أعلى للتغييرات التالية.

baseline يسجل دون تنفيذ، ولا يصلح ترحيلًا فشل جزئيًا.
