# خريطة الوثائق

يحفظ migrate التغييرات في ملفات إصدارات مرتبة. استخدم CLI أثناء النشر أو المكتبة داخل تطبيق Go.

- البداية: [SQLite](./quick-start)، [التثبيت](./installation)، [الإعدادات](./configuration).
- الإدارة: [SQL](./sql-migrations)، [التطبيق](./applying)، [التراجع](./rollback)، [السجل](./history).
- معالجة البيانات: [السكربتات](./scripting)، [الوحدات](./modules)، [الواجهة](./script-api)، [المعاملات](./script-transactions)، [الأمثلة](./examples).
- التكامل: [Go](./go-library)، [SSH](./ssh-tunnels).
- المرجع: [الأوامر](./commands)، [القواعد](./databases)، [حل المشكلات](./troubleshooting).

تحقق من `migrate version` و[ملاحظات الإصدار](../releases) لمعرفة ميزات النسخة المثبتة.
